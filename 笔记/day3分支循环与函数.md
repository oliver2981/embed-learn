# Day 3｜分支、循环与函数

> 目标：让程序不再"一条直线走到底" —— 会用 `if` / `switch` 做选择，会用 `while` / `do-while` / `for` 重复，会用 `break` / `continue` 控制节奏；再学会把一段逻辑抽成**函数**，并且分清"打印结果"和"返回结果"的区别。

---

## 一、先看全局：程序只有三种结构

C 语言里所有代码，拆到最底层只有这三种：

| 结构 | 一句话 | 对应语句 |
| :--- | :--- | :--- |
| **顺序** | 从上到下一条条执行 | 所有普通语句 |
| **选择（分支）** | 满足条件才执行 | `if` / `switch` |
| **循环** | 满足条件就反复执行 | `while` / `do-while` / `for` |

前两天的代码全是"顺序"，今天把后两种补上。**分支管"走哪条路"，循环管"走几遍"，函数管"把路打包"。**

## 二、if / else if / else

### 1. 三种写法

```c
// ① 只有 if：条件成立才执行
if (条件表达式) {
    语句;
}

// ② if + else：二选一，必走其中一条
if (条件表达式) {
    语句1;
} else {
    语句2;
}

// ③ if + else if + else：多选一
if (条件1) {
    语句1;
} else if (条件2) {
    语句2;
} else if (条件3) {
    语句3;
} else {
    语句4;   // 前面全不成立才走这里
}
```

### 2. 必须记住的规则

1. 条件**必须放括号里**：`if (x > 0)`，不能写 `if x > 0`。
2. **非 0 为真，0 为假**。所以 `if (1)` 恒真、`if (0)` 恒假；`if (x)` 等价于 `if (x != 0)`。
3. `else` 不能单独出现，必须跟某个 `if` 配对。
4. `else if` 本质是 `else { if (...) ... }` 的简写，不是新语法。
5. **从上往下判断，第一个为真的分支执行完，后面的分支全部跳过** —— 所以顺序写错了结果就错。
6. 分支里有多条语句必须用 `{}` 包起来；只有一条可以省，但**建议永远加**（以后加第二行时不会踩坑）。
7. `else` 与**最近的、还没配对的 `if`** 配对（"悬空 else"规则）。
8. `if (x == 1)` 别写成 `if (x = 1)` —— 后者是**赋值**，把 1 塞进 x，结果恒为真，编译器只会给个警告。
9. 浮点数**不要直接用 `==`** 比较，用误差范围：`if (fabs(a - b) < 1e-6)`（`fabs` 在 `<math.h>` 里）。

### 3. 示例：成绩等级

```c
if (score < 0 || score > 100) {
    printf("非法成绩\n");
} else if (score >= 90) {
    printf("A\n");
} else if (score >= 80) {
    printf("B\n");
} else if (score >= 70) {
    printf("C\n");
} else if (score >= 60) {
    printf("D\n");
} else {
    printf("E\n");
}
```

**顺序为什么重要**：`else if` 链是"先到先得"。如果先写 `score >= 60`，那 95 分也会落进 `>= 60` 这一档，直接打 `D`。所以**按范围从大到小（或从小到大）一路排下来**，别让宽条件挡住窄条件。

### 4. 悬空 else：不加大括号的坑

```c
if (a > 0)
    if (b > 0)
        printf("都大于0\n");
else
    printf("a <= 0\n");   // 这个 else 实际配对的是哪个 if？
```

答案：配对 `if (b > 0)`，不是外层那个。缩进骗人，**编译器只看"最近的未配对 if"**。想让它配外层，就给内层加 `{}`。

## 三、switch / case / default

一个变量要跟一堆**固定值**比对时，`switch` 比一长串 `else if` 干净。

### 1. 语法

```c
switch (整型表达式) {
    case 常量1:
        语句;
        break;
    case 常量2:
        语句;
        break;
    default:
        语句;
        break;
}
```

### 2. 规则

1. `switch` 后面必须是**整型类**表达式：`int`、`char`、`short`、`long`、枚举。**不能是 `float` / `double` / 字符串**。
2. `case` 后面必须是**常量表达式**：`case 1:`、`case 'A':` 可以，`case n:`（变量）不行。
3. 同一个 `switch` 里 `case` 常量不能重复。
4. `default` 最多一个，位置随便放，习惯写最后。
5. **`break` 是出口**。漏了 `break` 会继续往下执行后面的 `case`，这叫**穿透（fall-through）**。
6. 多个 `case` 可以共用一段代码（写成连续几个 `case`，最后一个才写语句）。
7. `switch` 只适合"等于某个值"的判断；**范围判断（`>= 90` 这种）只能用 `if`**。
8. `switch` 里的 `break` 只跳出这个 `switch`，跳不出外层循环。
9. 如果某个 `case` 里要声明变量，用 `{}` 包成代码块。

### 3. 示例：简易菜单

```c
switch (choice) {
    case 1:
        printf("新建\n");
        break;
    case 2:
        printf("打开\n");
        break;
    case 3:
    case 4:                     // 3 和 4 共用同一段处理
        printf("保存/另存为\n");
        break;
    default:
        printf("无效选项\n");
        break;
}
```

### 4. 穿透演示

```c
int x = 2;

switch (x) {
    case 1:
        printf("1\n");
    case 2:
        printf("2\n");
    case 3:
        printf("3\n");
        break;
    default:
        printf("default\n");
}
```

`x = 2` 从 `case 2` 进去，因为没有 `break` 就一直往下走，输出：

```text
2
3
```

> 记法：`switch` 找到入口就"往下滑"，`break` 才是刹车。**故意穿透要写注释**，否则三个月后自己都看不懂。

## 四、while 循环

### 1. 语法

```c
while (条件表达式) {
    循环体;
}
```

### 2. 执行顺序

判断条件 → 成立就执行循环体 → 回到判断 → …… → 不成立就退出。

**条件一开始就是假，循环体一次都不执行**（最少 0 次）。

### 3. 示例：打印 1~5

```c
#include <stdio.h>

int main(void) {
    int i = 1;

    while (i <= 5) {
        printf("%d ", i);
        i++;
    }

    return 0;
}
```

输出：`1 2 3 4 5`

### 4. 最常见死法：忘了更新变量

```c
int i = 1;

while (i <= 5) {
    printf("%d ", i);
    // 忘了 i++，i 永远等于 1，条件永远为真 → 死循环
}
```

> 铁律：**循环体里一定要有让条件最终变假的操作**。写循环时先问自己一句："谁会把这个条件干掉？"

## 五、do-while 循环

### 1. 语法

```c
do {
    循环体;
} while (条件表达式);
```

注意：`while (...)` 后面**有分号**，这是 `do-while` 的语法要求，漏了直接编译报错。

### 2. 执行顺序

先执行一次循环体 → 再判断条件 → 成立就回去再来一遍 → 不成立就退出。

**至少执行一次**，这就是它和 `while` 的唯一本质区别。

### 3. 示例：至少输入一次，输 0 结束

```c
#include <stdio.h>

int main(void) {
    int n;

    do {
        printf("请输入一个数字，输入0结束：");
        scanf("%d", &n);
        printf("你输入了：%d\n", n);
    } while (n != 0);

    return 0;
}
```

### 4. 适用场景

- 菜单程序（先显示菜单，再问选哪个）
- 用户输入校验（必须先拿到一次输入才能判断）
- 任何"至少要做一次"的动作

```c
do {
    printf("hello\n");
} while (0);      // 条件一开始就是假，但也执行了一次
```

## 六、for 循环

### 1. 语法

```c
for (初始化; 条件; 更新) {
    循环体;
}
```

### 2. 执行顺序

```text
初始化（只做一次） → 判断条件 → 执行循环体 → 更新 → 判断条件 → 执行循环体 → 更新 → ...
```

顺序别记反了：**判断在循环体前面，更新在循环体后面**。

### 3. 示例：1~100 求和

```c
#include <stdio.h>

int main(void)
{
    int sum = 0;
    for (int i = 0; i <= 100; i++) {
        sum += i;
    }

    printf("%d\n", sum);
    return 0;
}
```

输出：`5050`（从 0 加到 100，0 加不加都一样，所以结果和 1~100 的和相同）

### 4. for 里声明的变量，出了循环就没了

```c
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
printf("%d", i);   // 编译报错：i 未声明
```

`for (int i = ...)` 里的 `i` 属于**循环自己的作用域（代码块）**，循环一结束就销毁 —— 这点和 Python 很不一样（Python 的循环变量活到函数结束）。

两种解法：

| 需求 | 写法 |
| :--- | :--- |
| 循环外还要用这个值 | 变量**定义在循环外面**：`int i;` 然后 `for (i = 0; ...)` |
| 只是循环体内部计数 | 照旧写 `for (int i = 0; ...)`，最干净 |

> 顺带记一下：`for (;;)` 三个部分都能省，`for (;;)` 就是死循环（等价 `while (1)`）。

## 七、三种循环怎么选

| 循环 | 判断时机 | 最少执行次数 | 适合 |
| :--- | :--- | :---: | :--- |
| `while` | 先判断 | **0 次** | 次数不知道，只知道"干到条件不成立为止" |
| `do-while` | 后判断 | **1 次** | 至少要做一次（菜单、输入校验） |
| `for` | 先判断 | **0 次** | **次数明确**（1~100、遍历数组） |

选择口诀：**次数明确用 `for`，次数不明用 `while`，至少一次用 `do-while`。**

三个都能互相改写，但选对了读起来最省脑子。

## 八、break / continue / goto

### 1. break：立刻结束整个循环

```c
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;
    }
    printf("%d ", i);
}
```

输出：`1 2 3 4`

### 2. continue：跳过本次剩下的代码，直接进入下一次

```c
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;        // 偶数跳过，不打印
    }
    printf("%d ", i);
}
```

输出：`1 3 5 7 9`

> ⚠️ 在 `while` / `do-while` 里用 `continue` 要特别小心：`for` 的"更新"是语法自带的，`continue` 之后照样会 `i++`；但 `while` 的 `i++` 是写在循环体里的，如果它排在 `continue` 后面，就会被跳过去 → **死循环**。所以在 `while` 里，把更新语句放到 `continue` 之前（或干脆改用 `for`）。

### 3. goto（知道就行，别用）

```c
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (i * j == 42) {
            goto found;      // 一次跳出两层循环
        }
    }
}
found:
printf("找到了\n");
```

`goto` 能一步跳出多层循环，是它唯一还有点用的地方。但会打乱阅读顺序，**主流代码里基本禁用**；真要跳出深层循环，改用"标志变量 + `break`"更稳。

## 九、函数：把一段逻辑打包

### 1. 什么叫函数

```c
返回类型 函数名(形参列表)
{
    函数体;
    return ...;   // void 函数可以不写
}
```

- **函数名**：自己起的名字（标识符规则同变量）
- **形参**：函数接收的输入，`void` 表示不接收
- **返回类型**：函数交出来的结果类型；`void` 表示什么都不交

### 2. 示例：求两个数的和（两种写法）

**打印形式**（`void` + `printf`）：

```c
#include <stdio.h>

void sum(int num1, int num2) {
    int sum = num1 + num2;
    printf("%d", sum);
}

int main() {
    sum(20, 30);      // 屏幕上出现 50
    return 0;
}
```

**返回值形式**（`int` + `return`）：

```c
#include <stdio.h>

int sum(int num1, int num2) {
    int result = num1 + num2;   // 别再用 sum 当变量名，会遮蔽函数名
    return result;
}

int main(void) {
    int r = sum(20, 30);
    printf("%d", r);
    return 0;
}
```

### 3. 核心区别（这张表要背下来）

| 维度 | `void` + `printf` | `int` + `return` |
| :--- | :--- | :--- |
| 结果去哪 | 直接写到屏幕（副作用） | 交给调用者（数据流） |
| 调用者能否二次使用 | 不能，只能眼看 | 能，可相加、比较、存文件、再传给别的函数 |
| 可否测试 | 要截获 stdout 才能断言 | 直接 `assert(sum(20,30) == 50)` |
| 职责 | 计算 + 展示耦合在一起 | 只计算，展示交给调用者 |
| 组合性 | 差 | 好，可嵌套 `sum(sum(1,2), 3)` |

> 一句话：**`printf` 是"把结果扔出去"，`return` 是"把结果递回去"**。前者是副作用，后者是函数的值。返回值形式让函数变成纯粹的"输入 → 输出"映射 —— 这是可复用、可测试、可组合的前提。

### 4. 另外几条规矩

1. **先声明/定义，后调用**。函数定义写在 `main` 后面时，前面要先写原型：`int sum(int, int);`。C99 起不再允许"没声明就调用"，gcc 会给 `implicit declaration` 警告。
2. **值传递**：实参把值**拷贝**一份给形参，函数里改形参不会影响外面的变量。（想改外面，就得传地址 —— 这是指针要解决的，等第 2 周。）
3. `return` 有两个作用：**交回结果** + **立刻结束函数**。`void` 函数里写 `return;` 就是提前退出。
4. 非 `void` 函数要在**所有路径**上都返回一个值，否则开 `-Wall` 会警告。`void` 函数里一旦 `return;` 提前退出，后面的打印就丢了。
5. `main` 的 `return 0` 是交给操作系统的"退出码"，0 表示正常结束。

| `code/day3/func_sum.c` | 函数初体验 | `void sum(int, int)` 里直接 `printf` | 输出 `50` |

`for.c` 和 `while.c` 是同一件事的两种写法，对照着看最清楚：

```c
// for：三件事都写在括号里，紧凑
for (int i = 0; i <= 100; i++) {
    sum += i;
}

// while：三件事散在三个地方，啰嗦但灵活
int i = 0, sum = 0;
while (i <= 100) {
    sum += i;
    i++;
}
```

`primeNumber.c` 的思路值得记住 —— **"先假设成立，找到反例就推翻"**：

```c
int n;
scanf("%d", &n);

int is_prime = 1;              // 先假设是素数

if (n <= 1) {
    is_prime = 0;              // 1 和负数、0 都不是素数（边界单独处理）
} else {
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {      // 找到一个因子就够了
            is_prime = 0;
            break;             // 不用再找了
        }
    }
}

if (is_prime)
    printf("%d 是素数\n", n);
else
    printf("%d 不是素数\n", n);
```

> 优化方向：循环条件写成 `i * i <= n` 就够（因子成对出现，超过 √n 的那一半是重复的），判断 100 万以内的数会快很多。

## 十一、今天踩的坑

1. **在 `if` / `while` / `for` 后面多打了一个分号** —— 分号就是一条"空语句"，等于循环体或分支体是空的。这是今天最坑的一个：

   | 写法 | 实际效果 |
   | :--- | :--- |
   | `if (x > 0); { ... }` | 条件成立只执行空语句，`{ ... }` 那块**无条件执行** |
   | `while (i <= 5); { ... }` | 循环体是空的，`i` 永远不变 → **死循环** |
   | `for (i = 0; i < 5; i++); { ... }` | 循环空转 5 次，`{ ... }` 只执行 **1 次** |

   > 自查方法：看到 `)` 后面紧跟 `;`，就要停下来想一想。`// 错误：分号表示空语句` 这句注释就是给自己留的记号。

2. **以为 `for` 里声明的变量在外面还能用** —— `for (int i = 1; ...)` 的 `i` 只活在循环的代码块里，循环结束就销毁，出循环再引用直接编译报错。要在循环外继续用，就得把 `i` 定义在循环外面。

3. **函数里的局部变量和函数同名** —— 写 `int sum(int a, int b) { int sum = a + b; }` 时，局部变量 `sum` 会**遮蔽**函数名 `sum`，函数体内再调用 `sum(...)` 就会出错（编译器会报"不是函数"）。变量名换个字：`result`。

4. **素数判断漏了边界** —— 只写 `for (i = 2; i < n; i++)` 的话，输入 1 会走进"没找到因子 → 是素数"的结论，但 1 不是素数。所以**先把 `n <= 1` 单独拦掉**。

5. **`for(; i < prime; i++)` 把初始化省掉了** —— 语法上合法（`i` 在循环外先赋了值），但 `i` 一直挂在外面，第二次用同一段逻辑时容易忘了重置。初值能写进 `for` 括号里，就写进去。

6. **改了源码但跑的还是旧程序** —— 今天判断素数时，9 输入后没有任何输出，原因是 `output\primeNumber.exe` 里跑的还是改之前那版（`break` 之后没有 `else` 分支，判断为假时什么都不打印）。扩展有 `skip-if-compiled`，源码不比 exe 新就跳过编译。**遇到"代码改了结果没变"，先删 `output\*.exe` 再跑。**
